## 2. 操作顺序

决定顺序的几条铁律：

1. **EVE 在登出时写入设置，在登入时读取。** 因此编辑器的每次改动
   都必须在该角色**登出**的状态下保存；而每次对客户端所作所为的观察，
   都需要先**登出**再读取文件。
2. 每个方向前后都要抓取，否则 diff 什么也证明不了。
